Sobre

Antes de escrever código, eu trabalhava direto com pessoas: vendas, atendimento, design para clientes de todo o Brasil. Aprendi que o que realmente importa é entender quem está do outro lado antes de entregar qualquer solução.

Essa visão me acompanha no desenvolvimento: construo interfaces pensando em quem vai usar, não só em como o código vai rodar. Para mim, tecnologia é meio. O fim é sempre resolver um problema real de uma pessoa real.

Hoje curso ADS na PUC Minas e evoluo minha stack diariamente, com foco em front-end e expandindo para mobile com React Native e para back-end com Python e SQL.
